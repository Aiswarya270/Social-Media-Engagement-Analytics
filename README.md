# Social-Media-Engagement-Analytics
Python data analytics project focused on cleaning, analysing and visualizing social media engagement data using Pandas, NumPy, Matplotlib, Seaborn and Plotly.

## About the Project

This project is about analysing social media engagement data using Python. The main aim is to understand user behaviour, content performance and engagement trends.

## Dataset

The project uses the `social_media_engagement_5000.csv` dataset containing 5,000 records of social media engagement.

## Tools and Libraries Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## Project Tasks

1. Data Import and Setup
2. Data Cleaning
3. Data Exploration
4. Data Wrangling
5. Statistical Analysis
6. Data Visualization
7. Final Insights and Analysis

## Visualizations

Created different charts to understand social media engagement, including:

- Scatter Plot
- Line Chart
- Bar Chart
- Pie Chart
- Histogram
- Box Plot
- Count Plot
- Violin Plot
- Pair Plot
- Heatmap
- Swarm Plot/Strip Plot
- Interactive Plotly Charts

## Conclusion

This project helped me understand how to use Python for data cleaning, analysis and visualization. It also helped me explore social media engagement patterns and user behaviour.
